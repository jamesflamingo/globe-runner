For this project, I based my idea on the exercise we did in class with Jorge. Basically, I changed the game from a horizontal layout to a vertical one. The objects were uniform and attached to the edges of the screen, leaving a gap between them.
 
My idea was to implement gravity into the game, which I managed to do using examples from websites like W3Schools. However, I couldn't figure out how to make the player jump while still maintaining gravity, so I had to use AI to help me with that.

I managed to implement the main gameplay mechanic of dodging obstacles on my own. I also used AI to help me with some details, such as the trail left behind by the globe, as well as fixing some visual issues and calculation errors.
